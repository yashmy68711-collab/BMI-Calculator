# GUI BMI Calculator (Python)

## About

A simple GUI BMI Calculator built using Python and Tkinter.
This application calculates Body Mass Index (BMI) based on a user's weight and height and displays the corresponding health category.

---

## ✨ Features

✔️ Calculate BMI instantly
✔️ Health status classification
✔️ User-friendly GUI
✔️ Input validation
✔️ Clear button support

---

## 🛠️ Tech Used

* Python
* Tkinter

---

## 🚀 How to Run

1. Download the project
2. Open the Python file
3. Run the program
4. Enter your weight (kg)
5. Enter your height (m)
6. Click **Calculate BMI**
